## Windows Installer

This folder contains NSIS installer customization for Blur Sounds.

The app expects users to install [VB-Audio Hi-Fi Cable & ASIO Bridge](http://vincent.burel.free.fr/VirtualAudioApps/HiFiCableAsioBridgeSetup_v1007.zip) separately ([product page](https://vb-audio.com/Cable/index.htm)). After install, the NSIS finish dialog offers to open that download.
